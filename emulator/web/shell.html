Cheat sheet

Edit values

ENTER
insert last used value
ENTER,ENTER
insert next unused chain/phrase
ENTER+←/→
value −/+ 1
ENTER+↓/↑
value −/+ 16
ALT+ENTER
cut if filled, paste if empty
ALT+EDIT,ENTER
clone into next free slot

While selecting

ALT+EDIT
start a selection
arrows
resize the block
…again / 3×
grow to row / whole screen
EDIT
copy selection
ALT+ENTER
cut selection

These only apply once a selection is open — the keys mean something else the rest of the time.

Play

PLAY
start / stop
NAV+PLAY
stop chain when it ends
ALT+PLAY
play from current row
NAV+EDIT
mute track
NAV+ENTER
solo track
NAV+ALT
unmute everything

Mute/solo work on song, chain, phrase and mixer — the screens with a track under the cursor. Release NAV first to keep them latched.

In Song view

EDIT+↑/↓
page up / down
EDIT+←/→
Song ↔ Live mode

In Chain/Phrase/Instrument views EDIT+arrows warp to the previous/next one instead.
